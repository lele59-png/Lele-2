# Calculator Ringkas

Projek ini menyediakan kalkulator web ringkas yang boleh digunakan dalam pelayar web. Ia menyokong operasi asas (+, -, *, /) serta fungsi pembetulan dan titik perpuluhan.

## Cara Penggunaan
1. Buka fail `index.html` dalam pelayar web.
2. Klik butang pada papan kekunci untuk memasukkan nombor dan operasi.
3. Tekan `=` untuk mendapatkan hasil.
4. Tekan `C` untuk mengosongkan skrin.

## Teknologi
- HTML5
- CSS3
- JavaScript (ES6)
